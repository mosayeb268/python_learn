# سامانه آموزش جامع و تعاملی پایتون

این پروژه یک وب‌اپلیکیشن مدرن، تعاملی، کاملاً آفلاین و خودکفا است که برای آموزش گام‌به‌گام و دقیق **سه فصل اول کتاب آموزش جامع پایتون (تالیف مهندس عین‌الله جعفرنژاد قمی)** طراحی و پیاده‌سازی شده است.

---

## 🌟 ویژگی‌های برجسته سامانه

1. **پوشش کامل و موشکافانه سرفصل‌های ۳ فصل اول:**
   - **فصل اول:** مبانی و فلسفه پایتون، چرخه حیات و نحوه کارکرد مفسر (بایت‌کد و PVM)، مقایسه مفسر و کامپایلر، محیط‌های IDLE و VS Code، ساختار فایل‌های `.py`، دستور خروجی `print`، حساسیت به حروف (Case Sensitivity)، کامنت‌گذاری یک‌خطی و چندخطی، و قاعده حیاتی تورفتگی (Indentation).
   - **فصل دوم:** متغیرها و نام‌گذاری شناسه (قوانین و کلمات کلیدی)، انواع داده‌های عددی (`int`، `float`، `complex`)، رشته‌ها (`str`) و کاراکترهای گریز و ایندکس‌گذاری مثبت/منفی، مقادیر منطقی (`bool`) و تبدیل نوع (Type Casting)، عملگرهای هفت‌گانه حسابی و جدول تقدم ریاضی، عملگرهای مقایسه‌ای و انتساب ترکیبی، عملگرهای منطقی و بیتی، دستور دریافت ورودی تعاملی `input()` و تابع پیشرفته `print()` به همراه `sep`، `end` و `f-strings`.
   - **فصل سوم:** مفهوم تصمیم‌گیری و جریان کنترل، دستور شرطی ساده `if` و الزام دونقطه (`:`) و تورفتگی، ساختار دوحالته `if - else` و حل مسائل کلاسیک (زوج/فرد)، ساختار چندشاخه `if - elif - else` و سیستم رتبه‌بندی نمرات، شرط‌های تو در تو (Nested If)، عملگر شرطی سه‌تایی یک‌خطی (Ternary Operator)، ترکیب شروط با `and` و `or`، ساختار مدرن تطبیق الگو (`match - case`)، و حل گام‌به‌گام پروژه‌های الگوریتمی کتاب مانند محاسبه ریشه‌های معادله درجه دو ($ax^2 + bx + c = 0$) و ماشین‌حساب هوشمند شرطی.

2. **محیط تعاملی اجرای پایتون (Code Playground درون مرورگر):**
   - **۱۰۰٪ مستقل و آفلاین:** اجرای کدها به کمک موتور Skulpt کاملاً در مرورگر کاربر انجام می‌شود و هیچ‌گونه وابستگی به اینترنت یا سرور بیرونی ندارد.
   - **پشتیبانی کامل از تابع `input()` به صورت تعاملی:** کاربر هنگام اجرای کدهایی که درخواست ورودی دارند، کادر ورود تعاملی را در ترمینال مشاهده کرده و مقادیر را تایپ می‌کند.
   - **راهنمای هوشمند خطاهای پایتون به زبان فارسی:** در صورت بروز خطاهایی مانند `IndentationError`, `SyntaxError`, `NameError`, `TypeError`, `ValueError` جعبه راهنمای تشریحی فارسی علت خطا و شیوه رفع آن را نمایش می‌دهد.
   - **امکان انتقال هر مثال از متن درس به محیط اجرا:** کاربر با یک کلیک روی دکمه «اجرا در ویرایشگر» می‌تواند کدهای متن درس را تست و دستکاری کند.

3. **آزمون‌های مفهومی چهارگزینه‌ای (Quizzes):**
   - کوئیزهای هدفمند برای هر فصل با تحلیل خروجی کد و درک مفاهیم.
   - تحلیل و تشریح کامل چرایی درستی گزینه صحیح پس از پاسخ‌دهی.
   - کارنامه تحلیلی و ثبت درصد موفقیت کاربر.

4. **چالش‌های کدنویسی با تصحیح خودکار (Coding Challenges):**
   - مسائل واقعی و کاربردی با تست‌کیس‌های خودکار (Auto-grader).
   - راهنماهای گام‌به‌گام (Hints) و امکان مشاهده راه‌حل تشریحی در صورت نیاز.

5. **طراحی زیبا، استاندارد و فارسی (RTL & Dark/Light Mode):**
   - تایپوگرافی چشم‌نواز و بهینه‌شده برای زبان فارسی.
   - قابلیت سوییچ بین تم تیره (Dark Mode) و روشن (Light Mode).
   - ذخیره دائمی پیشرفت دانشجو (درس‌های خوانده‌شده، نتایج آزمون‌ها و تمرین‌ها) در LocalStorage.
   - تقلب‌نامه سریع (Cheat Sheet) و جستجوی لحظه‌ای (با کلید میانبر `Ctrl+K`).

## 🚀 نحوه راه‌اندازی و اجرا

پروژه به صورت یکپارچه با Vite و React توسعه یافته است:

```bash
# نصب پکیج‌ها (در صورت نیاز)
npm install

# اجرای سرور توسعه محلی
npm run dev
```

سپس در مرورگر خود آدرس زیر را باز فرمایید:
`http://localhost:5173`

برای ساخت نسخه نهایی و پروداکشن:
```bash
npm run build
npm run preview
```
